# Manchester English Academy Website

## 📧 FORM CONFIGURATION - READY TO USE!

The contact form is **already configured** to send emails to: **easyenglishclasses4you@gmail.com**

### How it works:
- Uses **FormSubmit.co** (FREE service)
- The first time someone submits the form, you'll receive a confirmation email at easyenglishclasses4you@gmail.com
- Click the confirmation link to activate
- After that, all form submissions will arrive automatically to your inbox

### If you need to change the email:
1. Open `script.js` file
2. Find line 109: `'https://formsubmit.co/ajax/easyenglishclasses4you@gmail.com'`
3. Replace with your preferred email address

2. Open index.html in any browser to test locally

3. Upload all files to your web hosting

4. When you receive the first form submission, check your email (easyenglishclasses4you@gmail.com) and confirm the FormSubmit activation
